# 净界（小米 / 澎湃 OS 广告过滤）

净界是一款本地 DNS 广告过滤工具，不依赖无障碍权限，不上传账号、浏览记录或统计数据。

## v0.12.0 界面与功能

- **总开关**：开启时启动本地 VPN、DNS 拦截和后台规则更新；关闭时一次停用净界开启的全部拦截功能。规则和用户设置会保留，重新开启即可恢复。
- **状态栏常驻详情**：可在 APP 内开启或关闭。开启后仅显示防护状态、当前档位和本次拦截次数，通知不可侧滑清除；关闭详情后仅保留 Android 对运行中 VPN 服务要求的最简提示。
- **三档防护**：把原先重复的多个规则开关合并为“稳定、增强、极致”三档。
  - 稳定：基础广告和跟踪域名，误拦截风险最低。
  - 增强：增加弹窗广告、国内移动广告 SDK 和小米系统推广规则，推荐日常使用。
  - 极致：使用更宽的主规则并叠加增强规则，覆盖更多，但误拦截风险更高。
- **视频广告实验过滤**：因更容易影响视频播放，仍保留为单独开关。
- **规则管理**：合并自动同步、立即同步、自定义黑名单和白名单。
- **30 秒广告诊断**：在目标广告出现时记录内存中的 DNS 请求，按域名特征给出高可信候选；由用户勾选后才加入临时测试拦截，可一键撤销。
- **最近 DNS 请求**：显示最近的放行/拦截结果，只保存在当前进程内存中，不上传、不写入日志文件。
- **多应用兼容管理**：支持 15 组常用购物、支付、社交、视频、内容、地图、旅行和音乐 APP。每组可独立选择正常过滤或兼容优先；保存后自动重启本地 VPN，并可一键恢复推荐设置。
- **后台与隐私**：提供自启动、省电策略、VPN 常驻和隐私说明入口。

规则在联网时自动更新；防护启用期间，后台任务会定期检查，成功更新后的 24 小时内不会重复下载。升级时，旧版多个规则开关会自动迁移到最接近的三档模式。

## 能力边界

- DNS 过滤适合阻止独立广告域名、跟踪域名和部分开屏广告，不会解密 HTTPS，也不会读取页面内容。
- 与正常图片共用同一域名的广告无法安全过滤；否则会出现美团等应用正常图片不显示的问题。
- 与视频内容共用域名、必须观看后由服务器发放奖励的广告，无法保证屏蔽。
- DNS 无法拦截 App 直接发起的显式 Intent、深链或自定义协议跳转。
- “摇一摇”需要在澎湃 OS 的应用权限或开发者选项中限制传感器，普通应用无法在无 root、无无障碍的情况下替其他应用拦截传感器。
- 本地 VPN 不能和另一款普通 VPN 同时运行。

## 构建

项目使用 Android Gradle Plugin 8.13、Gradle 8.14.3、JDK 17、compileSdk 36、minSdk 26。

```bash
./gradlew lintDebug assembleDebug
```

调试 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。GitHub Actions 会在每次推送和拉取请求时执行相同检查，并上传调试 APK 构建产物。

发布签名不会保存在仓库中。需要本地发布包时，将 `signing.properties.example` 复制为 `signing.properties`，填写本机密钥路径和密码；也可以设置 `RELEASE_STORE_FILE`、`RELEASE_STORE_PASSWORD`、`RELEASE_KEY_ALIAS`、`RELEASE_KEY_PASSWORD` 环境变量。密钥、密码文件、SDK、依赖缓存和构建输出均已加入 `.gitignore`。
